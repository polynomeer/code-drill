# 구간 집합

예약된 시간대, 할당된 IP 대역, 이미 받은 바이트 범위처럼 정수 구간을 모아 두는 `RangeSet` 을 만든다.
`src/ranges/RangeSet.kt` 를 완성한다. `Span` 은 같은 패키지에 있다.

## 구간

구간 `[from, to)` 는 `from` 이상 `to` 미만의 정수다 — **끝점 `to` 는 들지 않는다.** 좌표는 `-10^18` 이상 `10^18` 이하다.

- `from == to` 인 구간은 비어 있다. 빈 구간을 더하거나 빼면 아무 일도 없고, 빈 구간을 덮는지 물으면 `true` 다.
- `from > to` 면 `add`, `remove`, `covers` 모두 `IllegalArgumentException` 이다.

## 연산

| 연산 | 하는 일 |
|---|---|
| `add(from, to)` | 구간의 정수를 모두 집합에 넣는다 |
| `remove(from, to)` | 구간의 정수를 모두 집합에서 뺀다 |
| `contains(x)` | `x` 가 집합에 있는가 |
| `covers(from, to)` | 구간의 정수가 **모두** 집합에 있는가 |
| `spans()` | 집합을 나타내는 구간들 — 아래 모양으로 |
| `size()` | 집합에 든 정수의 개수(`Long`) |

## `spans()` 의 모양

집합은 언제나 가장 적은 수의 구간으로 나타낸다. 즉 `spans()` 의 구간은

- 시작점 순으로 정렬돼 있고,
- 비어 있지 않고,
- **서로 겹치지도 맞닿지도 않는다** — `[1, 3)` 과 `[3, 5)` 를 더하면 `[1, 5)` 하나다.

더하기 하나가 여러 구간을 하나로 이을 수 있고, 빼기 하나가 구간 하나를 둘로 쪼갤 수 있다.
