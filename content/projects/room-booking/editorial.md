# 해설 — 회의실 예약

겹침 판정 하나가 이 문제의 절반이다. 반열린 구간 `[a, b)` 와 `[c, d)` 가 겹치는 조건은
`a < d && c < b` 이고, 등호를 하나라도 넣으면 끝과 시작이 같은 두 예약 — 10시에 끝나고 10시에
시작하는 — 이 부딪힌다. 회의실이 그렇게 돌지 않는다는 것이 요구사항이다.

옮기기는 **자기 자신을 겹침에서 뺀다.** `[10, 20)` 을 `[15, 25)` 로 옮기는 것은 자기 자리와
겹치지만 그것은 부딪힘이 아니다. 자신을 빼지 않으면 조금 늦추는 이동이 전부 막힌다. 그리고
**검사가 다 지난 뒤에만 바꾼다** — 먼저 지우고 검사하면 실패했을 때 원래 예약이 사라지고, 그것은
이체가 절반만 되는 것과 같은 실패다. 검사 순서(인자 → 중복 → 겹침)는 어떤 예외가 나가는지를
정하므로 요구사항의 일부다.

빈 구간은 정렬된 예약을 한 번 훑으며 커서를 옮기는 것으로 나온다. 커서가 여는 시각에서
출발해 예약의 시작보다 앞이면 그 사이가 빈 구간이고, 예약의 끝으로 옮긴다. 마지막 예약 뒤의
구간을 넣는 것을 잊기 쉽고, 예약이 없을 때 하루 전체가 되는 것은 그 규칙이 저절로 준다.
길이 0 인 구간은 `start > cursor` 의 부등호가 걸러 낸다.
