# 경로 글롭

`src/**/*.py` 같은 패턴이 파일 경로와 맞는지 판단하는 `match(pattern, path)` 를 만든다. `pathglob/matcher.py` 를
완성한다. 패턴이 경로 **전체**와 맞으면 `True` 다. 대소문자를 가린다.

## 조각

경로와 패턴은 `/` 로 나눈 **조각**들이다. 패턴의 조각 하나는 경로의 조각 하나와 맞는다 — 조각 `**` 만 예외다(아래).
경로와 패턴은 비어 있지 않고, `/` 로 시작하거나 끝나지 않으며, 빈 조각(`a//b`)이 없다. 패턴에 `\/` 는 나오지 않는다.

## 조각 안에서

| 패턴 | 맞는 것 |
|---|---|
| 보통 글자 | 그 글자 |
| `?` | 글자 하나 |
| `*` | 0 개 이상의 글자 |
| `[...]` | 클래스 안의 글자 하나 |
| `\x` | 글자 `x` 그대로 — `\*` 는 별 글자, `\\` 는 역슬래시. 패턴 끝의 홀로 남은 `\` 는 역슬래시 글자다 |

어느 것도 `/` 와는 맞지 않는다 — 조각을 넘지 못한다. 조각 안의 `**`(예: `a**b`)는 `*` 와 같다.

## 문자 클래스

- `[abc]` 는 셋 중 하나, `[a-z]` 는 범위(양 끝 포함), 둘을 섞어 `[a-cx-z]` 처럼 쓸 수 있다.
- `[!...]` 는 **안에 없는** 글자 하나다.
- `[` 바로 뒤(또는 `[!` 바로 뒤)의 `]` 는 글자다: `[]a]` 는 `]` 나 `a`. 그 밖의 `]` 가 클래스를 닫는다.
- `-` 가 클래스의 처음이나 끝에 있으면 글자다: `[a-]`, `[-a]`.
- 클래스 안의 `\x` 는 글자 `x` 다: `[\]]`.
- 거꾸로 된 범위(`[z-a]`)는 아무 글자와도 맞지 않는다.
- **닫히지 않은 `[` 는 오류가 아니라 그냥 글자 `[` 다**: `[a` 는 경로 `[a` 와 맞는다.

## `**`

조각 전체가 `**` 이면 경로의 조각을 **0 개 이상** 건너뛴다. `a/**/b` 는 `a/b`, `a/x/b`, `a/x/y/b` 와 맞고, `**` 는
어떤 경로와도 맞고, `a/**` 는 `a` 와도 맞는다.

## 숨은 조각

`.` 으로 시작하는 조각(`.git`, `.env`)은 숨은 조각이다.

- 조각 안의 `*`, `?`, `[...]` 는 숨은 조각의 첫 `.` 과 맞지 않는다. 패턴 조각이 글자 그대로의 `.`(또는 `\.`)으로 시작해야
  숨은 조각과 맞는다: `*` 는 `.env` 와 맞지 않고 `.*` 는 맞는다. 조각 가운데의 `.` 은 보통 글자다.
- `**` 는 숨은 조각을 건너뛰지 않는다: `**/config` 는 `.git/config` 와 맞지 않고, `**/.git/config` 는
  `repo/.git/config` 와 맞는다.

## 빠르기

별이 여럿인 패턴(`*a*a*a*a*a*a*a*a*a*a*b`)도 200 글자짜리 경로에서 곧바로 답해야 한다.
