# 해설 — 로마 숫자

**쓰기는 열세 개의 값으로 탐욕이다.** 일곱 기호에 빼는 꼴 여섯(`CM`, `CD`, `XC`, `XL`, `IX`, `IV`)을 값으로 끼워 넣어
`1000, 900, 500, 400, …, 4, 1` 의 표를 만들면, 큰 값부터 들어가는 만큼 쓰는 것이 곧 표준 꼴이다. 빼는 꼴을 따로 다루는 분기가
사라진다. 범위(1..3999)는 처음에 거른다 — 4000 을 `MMMM` 으로 쓰는 것은 표준 꼴이 아니다.

**읽기는 "값을 구한 뒤 다시 써서 같은지"로 검사한다.** 값은 왼쪽부터 더하되, 기호가 바로 뒤 기호보다 작으면 뺀다. 그런데 이
규칙은 `IIII`(4), `IC`(99), `VV`(10), `IXIX`(18) 에도 값을 낸다 — 값을 내는 것과 표준 꼴인 것은 다르다. "같은 기호는 세 번까지",
"V 는 이어지지 않는다", "I 는 V 와 X 앞에서만 뺀다" 를 하나씩 막으려 하면 하나는 빠뜨린다. 구한 값을 표준 꼴로 다시 써서 원래
글자와 같은지 보면 모든 규칙이 한 줄로 확인된다. 모르는 기호(소문자 포함)는 값을 구할 때 걸리고, 빈 문자열은 처음에 거른다.

시험할 것을 고를 때는 요구사항의 줄마다 그것을 어기는 가장 짧은 입력을 하나씩 적는다: `4`, `3999`, `4000`, `IIII`, `IC`, `VV`,
`xii`, `""`. 그리고 1..3999 전부를 쓰고 다시 읽는 왕복 — 탐욕 표의 한 칸이 틀리면 거기서 걸린다.
