# 해설 — 순위표

순위 규칙 하나가 이 문제의 중심이다. **경쟁 순위**는 "나보다 점수가 높은 선수의 수 + 1" 이라 같은
점수는 같은 순위를 받고 그다음은 그만큼 건너뛴다 — `10, 8, 8, 5` 가 `1, 2, 2, 4` 다. "높은 점수의 종류
수 + 1"(밀집 순위, `1, 2, 2, 3`)과 다르고, 정렬한 목록의 위치(`1, 2, 3, 4`)와도 다르다. 그래서 `top` 의
`rank` 는 목록 위치가 아니라 같은 함수로 다시 계산한 값이어야 한다.

정렬은 두 단계다 — 점수 내림차순, 같은 점수는 이름 오름차순. 한 방향만 뒤집으면 동점의 순서가 틀린다.
초기화는 표에서 빼는 것이 아니라 0 점으로 두는 것이다: 선수 수가 그대로고, 0 점도 순위를 받는다
(0 점끼리도 동점이다).

`addScore` 는 **검사가 다 지난 뒤에만 적는다.** 누적이 0 아래로 내려가는 요청은 거절이고, 그때
처음 보는 선수까지 등록돼 버리면 `size()` 가 어긋난다 — "먼저 등록하고 검사"는 실패한 요청이 흔적을
남기는 순서다.
