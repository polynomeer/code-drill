# 작은 템플릿 엔진

이메일 본문이나 HTML 조각을 만드는 머스태시(Mustache) 꼴의 템플릿 엔진을 만든다. `src/tmpl/Template.java` 의
`render(template, data)` 를 완성한다. `data` 의 값은 `String`, 수, `Boolean`, `Map<String, ?>`, `List<?>` 가운데 하나다.

## 태그

| 태그 | 뜻 |
|---|---|
| `{{name}}` | 값을 글자로 — **HTML 이스케이프한다** |
| `{{{name}}}` | 값을 글자로 — 이스케이프하지 않는다 |
| `{{#name}}…{{/name}}` | 섹션 |
| `{{^name}}…{{/name}}` | 뒤집힌 섹션 |
| `{{.}}` | 지금 문맥 그 자체(문자열 목록을 돌 때) |

태그 안쪽 앞뒤의 공백은 무시한다: `{{ name }}`. 태그 밖의 글자는 그대로 낸다(`{` 하나나 `}}` 는 그냥 글자다).

- **이스케이프**: `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`, `"` → `&quot;`, `'` → `&#39;`.
- **값이 없으면** 빈 문자열이다. 수는 `String.valueOf` 로 쓴다.

## 이름 찾기

문맥은 스택이다. 처음엔 `data` 하나이고, 섹션에 들어가면 새 문맥이 위에 쌓인다. 이름은 **가장 안쪽 문맥부터 바깥으로** 찾아,
그 키를 가진 첫 `Map` 의 값을 쓴다.

**점 이름** `a.b.c` 는 첫 조각 `a` 만 위처럼 찾고, 나머지 `b`, `c` 는 찾은 값 안에서만 따라간다 — 중간에 없으면 값이 없는
것이다. 바깥 문맥에서 다시 찾지 않는다.

## 섹션

`{{#name}}` 의 값이

- `null`(없음), `false`, 빈 목록이면 — 몸통을 그리지 않는다.
- 비어 있지 않은 목록이면 — 원소마다 그 원소를 문맥으로 쌓고 몸통을 그린다.
- 그 밖의 값(`true`, `Map`, 문자열, 수 — 빈 문자열과 `0` 도)이면 — 그 값을 문맥으로 쌓고 몸통을 한 번 그린다.

`{{^name}}` 은 반대로, 값이 `null`, `false`, 빈 목록일 때만 몸통을 한 번 그린다.

섹션은 겹칠 수 있고, 같은 이름의 섹션이 안에 또 있을 수 있다. 목록의 원소는 `null` 이 아니다.

## 오류

다음은 모두 `IllegalArgumentException` 이다.

- 닫히지 않은 태그: `{{name`, `{{{raw}}`
- 열린 섹션과 이름이 다른 닫는 태그, 열지 않은 섹션을 닫는 태그
- 닫히지 않은 섹션

## 제출

`src/tmpl/Template.java` 를 고친다(다른 파일을 더해도 된다). `tests/` 아래의 파일은 채점 때 숨은 스위트로 덮인다. 테스트는
`import static codedrill.Assertions.*;` 의 단언으로 쓴다 — 표준 라이브러리 외의 의존성은 없다.
