# 해설 — 기간 표기

**읽기는 두 단계로 나눈다: 모양을 보고, 그다음 뜻을 본다.** 먼저 공백으로 자른 조각마다 "숫자 뒤에 단위가 붙은 부분이 하나
이상"(`(?:[0-9]+[a-z])+`)의 모양인지 본다. 숫자와 단위 사이의 공백, 단위 없는 수, 부호, 소수점, 쉼표는 모두 이 한 줄에서
걸린다 — 경우마다 따로 막으려 하면 하나씩 빠뜨린다. 모양이 맞으면 조각을 이어 붙여 부분을 하나씩 꺼낸다.

**순서와 중복은 "다음에 올 수 있는 가장 큰 단위" 하나로 막는다.** 단위를 큰 것부터 0, 1, 2, 3 으로 번호 매기고, 부분의 단위
번호가 지금까지 본 마지막 단위 번호보다 커야 한다고 하면, 거꾸로 온 것(`30m1h`)과 되풀이된 것(`1h1h`)이 같은 비교에서
걸린다. 같은 것도 막아야 하니 "크거나 같음"이 아니라 "큼"이다. 모르는 단위는 번호가 없어 걸린다.

**쓰기는 큰 단위부터 몫과 나머지다.** 단위마다 `divmod` 로 몫을 떼고, 몫이 0 이면 그 부분을 쓰지 않는다. 그러면 0 초는 아무
부분도 남지 않으니 따로 `"0s"` 로 둔다. 음수는 처음에 거른다. 쓰기와 읽기가 서로의 거꾸로라는 것(`parse(format(n)) == n`)은
테스트 하나로 많은 값을 한꺼번에 확인하는 좋은 성질이다.

시험할 것을 고를 때는 요구사항의 줄마다 그것을 어기는 가장 짧은 입력을 하나씩 적는다: `30m1h`, `1h1h`, `90`, `1 h`,
`"1h 30m"`, `0`, `3601`, `-1`. 공개 테스트는 그중 어느 것도 묻지 않는다.
