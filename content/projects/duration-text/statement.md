# 기간 표기

설정 파일의 `timeout = "1h30m"` 처럼 사람이 쓰는 기간 표기를 초로 읽고, 초를 같은 꼴로 다시 쓴다.
`durations/text.py` 의 두 함수를 완성한다.

## 단위

| 단위 | 뜻 | 초 |
|---|---|---|
| `d` | 일 | 86 400 |
| `h` | 시간 | 3 600 |
| `m` | 분 | 60 |
| `s` | 초 | 1 |

## `parse_duration(text) -> int`

기간은 **부분**들의 나열이고, 부분은 0 이상의 정수 바로 뒤에 단위가 붙은 것이다(`90s`, `05m`). 값은 부분들의 초를 더한 것이다.

- 단위는 **큰 것부터** 오고 **한 번씩만** 온다. 건너뛰는 것은 된다: `1d5s` 는 되고 `30m1h`, `1h1h` 는 안 된다.
- 부분과 부분 사이, 그리고 앞뒤에는 공백이 있어도 된다: `"1h 30m"`, `" 90s "`. 숫자와 단위 사이에는 공백이 없다: `"1 h"` 는
  안 된다.
- 단위가 없는 수(`"90"`, `"1h30"`), 부호(`"-5s"`, `"+5s"`), 소수(`"1.5h"`), 대문자 단위(`"1H"`), 모르는 단위(`"3w"`), 그 밖의
  글자는 안 된다. 비었거나 공백뿐이어도 안 된다.

안 되는 것은 모두 `ValueError` 다.

## `format_duration(seconds) -> str`

초를 위의 꼴로 쓴다. 큰 단위부터 채우고(`90` → `1m30s`), **0 인 부분은 쓰지 않는다**(`3601` → `1h1s`). 공백은 넣지 않는다.
`0` 은 `"0s"` 다. 음수는 `ValueError`.

어떤 0 이상의 정수 `n` 에 대해서도 `parse_duration(format_duration(n)) == n` 이다.
