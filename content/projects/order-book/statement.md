# 호가창 체결 엔진

거래소의 호가창을 만든다. `src/book/OrderBook.java` 의 `OrderBook` 을 완성한다. `Order`·`Trade`·`Level`·`Side`·
`OrderType` 은 `src/book/` 의 다른 파일에 있고 고치지 않는다. 가격과 수량은 정수(`long`)다.

## `submit(order): List<Trade>`

들어온 주문을 **상대편**의 쉬고 있는 주문과 체결하고, 일어난 체결을 일어난 순서대로 돌려준다.

- **가격 우선**: 사는 주문은 가장 싼 파는 주문부터, 파는 주문은 가장 비싼 사는 주문부터 만난다.
- **시간 우선**: 같은 가격이면 먼저 쉬기 시작한 주문부터 만난다.
- 지정가(`LIMIT`) 주문은 상대 가격이 자기 가격보다 좋거나 **같은** 동안 체결한다 — 사는 주문은 `파는 값 ≤ 사는 값`,
  파는 주문은 `사는 값 ≥ 파는 값`. 시장가(`MARKET`) 주문은 가격을 보지 않고 상대편이 빌 때까지 체결한다.
- **체결 가격은 쉬고 있던 주문의 가격**이다. 한 번의 체결 수량은 두 주문의 남은 수량 중 작은 쪽이다.
- `Trade(buyOrderId, sellOrderId, price, quantity)` — 사는 쪽과 파는 쪽의 번호를 제자리에 넣는다.
- 다 체결하고도 남으면, 지정가 주문은 남은 수량으로 **자기 가격에 쉰다**(그 가격의 줄 맨 뒤). 시장가 주문의 남은 수량은
  버린다.

## `cancel(orderId): boolean`

쉬고 있는 주문이면 지우고 `true`. 없는 번호, 다 체결된 주문, 이미 취소된 주문은 `false`. 지워도 같은 가격의 다른
주문의 순서는 그대로다.

## `depth(side, levels): List<Level>`

그쪽에 쉬고 있는 주문을 가격마다 수량을 합쳐, 좋은 가격부터 많아야 `levels` 개. 사는 쪽은 비싼 값부터, 파는 쪽은 싼
값부터다. **수량이 0 인 가격은 없다** — 다 체결되거나 취소된 가격대는 사라진다.

## 잘못된 주문

`IllegalArgumentException` 이고, 호가창은 아무것도 바뀌지 않는다.

- 수량이 0 이하, 지정가인데 가격이 0 이하, 빈 칸(`null`)이 있다.
- **이미 쓴 주문 번호** — 지금 쉬고 있는 주문만이 아니라, 다 체결되었거나 취소되었거나 시장가로 지나간 주문의 번호도
  다시 쓸 수 없다.

## 제출

`src/book/OrderBook.java` 를 고친다. 필드와 도우미 클래스는 마음대로 더한다. `tests/` 아래의 파일은 채점 때 숨은
스위트로 덮인다. 테스트는 `import static codedrill.Assertions.*;` 의 `assertEquals`·`assertTrue`·`assertFalse`·
`assertNull`·`assertThrows` 를 쓴다 — 표준 라이브러리 외의 의존성은 없다. 테스트는 이름이 `Test` 로 끝나는 클래스의
`public void test…()` 메서드다.
