# 해설 — 분·시 일정식

읽기와 셈을 나눈다. **읽기**는 칸 → 항목 → 값 집합이다: 항목 하나를 `범위/간격` 으로 쪼개고, 범위는
`*`·`a`·`a-b` 셋 중 하나이며, 간격은 `*` 와 `a-b` 에만 붙는다. 값 집합으로 두면 중복(`1,1`)은 저절로
사라지고, 분과 시의 곱이 하루의 실행 시각이다.

간격의 기준이 이 문제에서 가장 자주 틀리는 자리다 — `5-20/6` 은 **범위의 시작**에서 6 씩(`5, 11, 17`)
이지 6 의 배수(`6, 12, 18`)가 아니다. `*/n` 이 `0, n, 2n, …` 인 것은 `*` 의 시작이 0 이기 때문이지
배수라서가 아니다. `range(lo, hi + 1, step)` 하나가 두 경우를 같이 맞힌다.

**거절**은 세 종류다: 범위 밖 값, 뒤집힌 범위(`20-5` 를 빈 범위로 두면 아무것도 안 돌고 아무도 모른다),
모양이 틀린 것(빈 항목, 칸 수, 하나의 값에 붙은 간격). 전부 `InvalidExpression` 이라야 호출자가 하나로
잡는다.

`next_run` 은 "엄격히 뒤"이고 하루를 넘으면 `1440 + 첫 시각` 이다. 같은 시각을 돌려주면 방금 돈 일이
바로 다시 돌고, 다음 날로 넘기지 않으면 자정 전 마지막 실행 뒤에 호출한 쪽이 과거를 받는다.
