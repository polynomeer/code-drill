# 해설

## 관찰

부분배열 `[i, j]` 의 합은 누적 합 `P[j] - P[i-1]` 이다. 이것이 k 의 배수라는 것은 `P[j]` 와 `P[i-1]` 을 k 로 나눈 **나머지가 같다**는 것이다. 그러니 답은 "나머지가 같은 누적 합 쌍의 수"이고, 나머지마다 몇 번 나왔는지만 세면 된다.

## 접근

나머지별 개수 표를 두고 빈 접두사의 나머지 0 을 1 로 시작한다. 원소를 하나씩 더하며 누적 합의 나머지를 구하고, 표에서 그 나머지의 개수를 답에 더한 뒤 표를 하나 올린다. 음수의 나머지는 언어의 `%` 가 음수를 줄 수 있으므로 `((x % k) + k) % k` 로 0 이상에 맞춘다.

## 복잡도

O(n + k) 시간, O(k) 공간. 시작점마다 끝점을 늘려 가며 합을 세면 O(n²) 이고, 20 만 개면 200 억이다.

## 발전 과정

모든 부분배열 → 누적 합으로 구간 합을 O(1) 에 → "합이 배수"를 "나머지가 같다"로 바꿔 한 번 훑기. 세 번째가 이 문제의 관찰이고, 합이 k 인 부분배열 수와 같은 뼈대다.

## 흔히 무너지는 곳

음수 누적 합의 나머지를 맞추지 않는 것 — -2 와 3 이 다른 칸에 간다. 빈 접두사를 세어 두지 않는 것 — 처음부터 시작하는 부분배열을 놓친다. 개수를 올린 뒤에 더하는 것 — 자기 자신과의 쌍을 센다.
