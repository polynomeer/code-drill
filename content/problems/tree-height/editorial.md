# 해설

## 관찰

정점의 깊이는 부모의 깊이 + 1 이다. 한 번 계산한 깊이를 기억해 두면 각 정점은 한 번만 올라간다. 부모가 자식보다 먼저 온다는 보장은 없다.

## 접근

정점마다 깊이를 모르는 조상까지 올라가며 경로를 쌓고, 아는 조상(또는 루트)에서부터 내려오며 깊이를 채운다. 최댓값이 답이다.

## 복잡도

O(n) 시간, O(n) 공간.

## 발전 과정

정점마다 루트까지 다시 올라가는 O(n²) → 메모 O(n).

## 흔히 무너지는 곳

정점 수를 세어 하나 큰 값을 내는 것. 배열 순서를 믿고 한 번만 훑는 것.
