# 해설

## 관찰

길이별로 '그 길이의 증가 수열을 만드는 가장 작은 끝값'을 유지하면, 새 값은 그 배열에서 자기 자리를 이분 탐색으로 찾는다. 배열은 항상 정렬돼 있다.

## 접근

tails 배열을 둔다. 값마다 tails 에서 자기 이상인 첫 자리를 찾아 덮어쓰고, 없으면 끝에 붙인다. tails 의 길이가 답이다.

## 복잡도

O(n log n) 시간, O(n) 공간.

## 발전 과정

모든 부분 수열 2^n → 위치별 DP O(n²) → tails + 이분 탐색 O(n log n).

## 흔히 무너지는 곳

엄격히 증가이므로 같은 값은 자기 자리를 덮어써야 한다 — '이상'이 아니라 '초과'를 찾으면 틀린다. tails 가 실제 수열이라고 착각하는 것.
