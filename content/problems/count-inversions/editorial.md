# 해설

## 관찰

역순 쌍을 세는 것은 정렬 과정에서 원소가 얼마나 뛰어넘어졌는지를 세는 것이다. 병합 정렬의 병합 단계에서 오른쪽 원소가 먼저 나올 때, 왼쪽에 남은 개수만큼이 역순 쌍이다.

## 접근

병합 정렬을 하되 병합 중 오른쪽에서 원소를 꺼낼 때마다 왼쪽에 남은 원소 수를 답에 더한다.

## 복잡도

O(n log n) 시간, O(n) 공간.

## 발전 과정

모든 쌍 O(n²) → 병합 정렬에 세기를 얹기 O(n log n).

## 흔히 무너지는 곳

같은 값을 역순으로 세는 것. 개수가 Int 를 넘는 큰 입력.
