# 해설

## 관찰

루트에서 정점 `v` 까지의 누적합을 `P[v]` 라 하면 조상 `a` 에서 `v` 까지 내려가는 경로의 합은 `P[v] - P[a]` 다. 그래서 `v` 에서 끝나는 경로 중 합이 `target` 인 것은 조상 중 `P[a] = P[v] - target` 인 것의 수 — 배열에서 합이 `k` 인 구간을 누적합과 해시맵으로 세는 것과 같은 모양이다. 값이 음수라 누적합이 오르내리므로 "합이 넘으면 끊는" 가지치기는 틀린다.

## 접근

DFS 로 내려가며 조상들의 누적합을 해시맵에 센다(루트 위의 빈 경로 `0` 도 하나). 정점에 들어갈 때 `P[v] - target` 의 수를 더하고 `P[v]` 를 세고, **되돌아올 때 뺀다** — 안 빼면 다른 가지의 정점이 조상으로 세어진다. 사슬이 10 만이면 재귀가 넘치므로 명시적 스택으로 돈다.

## 복잡도

O(n) 시간과 공간. 정점마다 아래로 다 내려가면 사슬에서 O(n²) 이고 10 만에서 50 억이다.

## 발전 과정

모든 정점에서 시작해 내려가는 풀이(맞지만 느리다) → 합이 넘으면 끊는 가지치기(음수에서 틀린다) → 누적합과 해시맵 → 되돌아올 때 빼기.

## 흔히 무너지는 곳

루트에서 시작하는 경로만 세는 것, 되돌아올 때 해시맵에서 빼지 않는 것, 합이 넘으면 끊는 것.
