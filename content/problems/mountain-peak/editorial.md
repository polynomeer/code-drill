# 해설

## 관찰

산 모양 배열에서 어떤 칸 `m` 의 오른쪽 이웃이 더 크면 `m` 은 오르막 위라 꼭대기는 `m` 보다 오른쪽이다. 더 작으면 `m` 은 내리막
위이거나 꼭대기 자신이라 꼭대기는 `m` 이하다. 한 번 비교로 구간의 절반을 버릴 수 있다.

## 접근

`[low, high]` 를 배열 전체로 두고 `low < high` 인 동안 가운데 `mid` 를 본다. `nums[mid] < nums[mid + 1]` 이면 `low = mid + 1`,
아니면 `high = mid` — **`mid` 를 버리지 않는다**, `mid` 가 꼭대기일 수 있다. 한 칸이 남으면 그것이 꼭대기의 자리다.
`low < high` 라 `mid + 1` 은 언제나 배열 안이다.

## 복잡도

O(log n) 시간, O(1) 공간.

## 발전 과정

"이웃과 견주어 어느 쪽에 답이 있는지 아는" 이분 탐색은 아무 봉우리 찾기, 회전 배열의 최솟값, 산 배열에서 값 찾기(꼭대기를 찾은
뒤 양쪽에서 각각 이분 탐색)로 이어진다.

## 흔히 무너지는 곳

- 내리막에서 `mid` 까지 버린다.
- 자리 대신 꼭대기 값을 낸다.
- 배열의 가운데를 낸다.
