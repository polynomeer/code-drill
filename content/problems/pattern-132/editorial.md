# 해설

## 관찰

찾는 것은 `nums[i] < nums[k] < nums[j]` 이고 자리는 `i < j < k` 다. 가운데 `j` 가 가장 큰 값이고,
`k` 는 그보다 작으면서 `i` 보다는 커야 한다. `j` 를 정해 놓고 양쪽을 뒤지면 두 겹이다.

## 접근

오른쪽에서 왼쪽으로 한 번 훑는다. 스택에는 아직 `nums[j]` 가 될 수 있는 값을 담는다. 새 값 `x` 가
스택 위의 값들보다 크면 그것들을 밀어내는데, **밀려난 값 중 가장 큰 것**을 세 번째 값으로 기억한다.
밀려났다는 것은 왼쪽에 더 큰 값(`x`)이 있다는 뜻이므로, 기억한 값보다 작은 값이 나중에(즉 더 왼쪽에)
나오면 그것이 `nums[i]` 다.

## 복잡도

O(n) 시간, O(n) 공간. 각 값은 한 번 들어가고 한 번 나온다.

## 발전 과정

같은 틀이 "다음으로 큰 값", "히스토그램의 최대 직사각형"과 같다 — 단조 스택은 "언젠가 쓸 값을 정렬된
상태로 미뤄 두는" 장치다.

## 흔히 무너지는 곳

- 밀려난 값 중 처음 것을 기억한다 — 가장 큰 것이 남아야 `nums[i]` 의 자리가 넓어진다.
- 한 번에 하나만 밀어낸다 — 스택의 단조성이 깨진다.
- 같은 값을 "사이"로 친다 — 셋은 서로 달라야 한다.
