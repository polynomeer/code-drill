# 해설

## 관찰

행마다 하나씩 놓으면 행 충돌은 없다. 열은 c 로, 대각선은 r-c 와 r+c 로 표시한다. 놓았다가 반드시 되돌린다.

## 접근

열·대각선 두 개의 표시 배열을 들고 행 순서로 재귀한다. 놓을 수 있는 열마다 표시하고 내려갔다가 돌아오면 지운다. 마지막 행을 넘으면 하나로 센다.

## 복잡도

O(n!) 시간, O(n) 공간.

## 발전 과정

모든 배치를 시험하는 n^n → 행마다 하나로 줄여 n! → 표시로 가지치기.

## 흔히 무너지는 곳

되돌리기를 빠뜨리는 것. 대각선을 하나만 보는 것. 하나 찾고 멈추는 것.
