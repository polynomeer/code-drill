# 해설

## 관찰

창 `[start, i]` 에 같은 글자가 없다는 성질을 유지하며 `i` 를 늘린다. 새 글자 `text[i]` 가 창 안에 이미 있으면, 그 글자가 마지막으로 나온 자리의 **다음**까지 `start` 를 당기면 다시 성립한다. 글자마다 마지막 위치를 기억하면 "창 안에 있는가"는 `last >= start` 한 번이다.

## 접근

`start = 0`, 글자별 마지막 위치 표. `i` 를 훑으며 `last[c] >= start` 면 `start = last[c] + 1`, 표를 갱신하고 `i - start + 1` 로 최선을 갱신한다. 되돌아가지 않는 것이 중요하다 — 창 밖의 옛 자리(`last < start`)는 무시한다.

## 복잡도

O(n) 시간, 서로 다른 글자 수만큼의 공간. 시작점마다 집합을 새로 만들면 O(n²) 이고, 10 만 자면 100 억이다.

## 발전 과정

모든 부분 문자열 검사 → 시작점마다 늘리기 → 양끝이 각각 한 번씩만 움직이는 창. 창의 왼쪽 끝을 "당기기만" 하는 것이 O(n) 의 근거다.

## 흔히 무너지는 곳

창 밖에 있던 글자의 옛 자리로 왼쪽 끝을 되돌리는 것 — `abba` 에서 창이 다시 넓어진다. 왼쪽 끝을 반복된 글자의 자리 자체로 당기는 것 — 같은 글자 둘이 남는다. 연속 조건을 잊고 서로 다른 글자 수를 답하는 것.
