# 해설

## 관찰

순환이 없으면 정점을 위상 순서로 늘어놓을 수 있고, 그 순서로 `u` 를 꺼낼 때 `u` 에 이르는 가장
긴 경로 `dist[u]` 는 이미 정해져 있다 — `u` 로 들어오는 정점은 전부 앞에 있다.

## 접근

Kahn: 진입 차수 0 인 정점을 큐에 넣고 꺼내며 나가는 간선마다 `dist[v] = max(dist[v], dist[u] + 1)`,
진입 차수를 줄여 0 이 되면 넣는다. 꺼낸 정점 수가 `n` 보다 적으면 순환이라 `−1`. 답은 꺼낸 정점의
`dist` 최댓값이다. 정점 하나면 0 이다.

## 복잡도

정점과 간선을 한 번씩, O(n + m). 큐와 배열 O(n + m).

## 발전 과정

재귀 DFS 로 기억하며 푸는 것도 답은 같지만 정점 10만의 사슬에서 **스택이 넘친다** — 맞는 풀이가
RUNTIME_ERROR 로 끝난다. 제약이 풀이의 모양을 정하는 자리다. 출발점마다 따로 BFS 하면 O(n·m) 이다.

## 흔히 무너지는 곳

- 순환 검사를 빼먹는다 — 다 꺼냈는지 보지 않는다.
- 거리를 처음 닿을 때만 정한다 — 더 긴 경로가 나중에 와도 갱신하지 않는다.
- 재귀로 내려간다 — 깊은 사슬에서 스택 오버플로.
