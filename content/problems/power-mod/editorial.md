# 해설

## 관찰

지수를 반으로 쪼갠다. base^e = (base^(e/2))² 이고 e 가 홀수면 base 를 한 번 더 곱한다. 곱할 때마다 나머지를 취해야 넘치지 않는다.

## 접근

결과 1 에서 시작해 지수의 비트를 아래부터 본다. 비트가 켜져 있으면 결과에 base 를 곱하고, 매 단계 base 를 제곱한다. 곱셈은 Long 으로 하고 매번 나머지를 취한다.

## 복잡도

O(log e) 시간, O(1) 공간.

## 발전 과정

e 번 곱하는 O(e) → 분할 정복 O(log e).

## 흔히 무너지는 곳

Int 로 곱해 넘치는 것. 지수가 0 일 때 1. base 를 먼저 나머지로 줄이지 않는 것.
