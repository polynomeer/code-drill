# 해설

## 관찰

각 위치에서 '여기서 끝나는 부분합의 최대'를 알면 전체 답은 그것들의 최댓값이다. 여기서 끝나는 최대는 직전까지의 최대에 지금 값을 더한 것과 지금 값 하나 중 큰 쪽이다.

## 접근

값을 하나씩 보며 running = max(v, running + v), best = max(best, running) 을 유지한다. 시작값은 0 이 아니라 첫 원소다 — 부분 배열은 비어 있을 수 없다.

## 복잡도

O(n) 시간, O(1) 공간.

## 발전 과정

모든 구간 O(n²) → 누적합으로 구간 합을 O(1)로 만들어도 구간 수는 그대로 → 카데인 O(n).

## 흔히 무너지는 곳

전부 음수인 입력에서 0 을 돌려주는 것. 빈 부분 배열을 허용한 셈이다.
