# 최대 부분합

정수 배열 `nums` 에서 연속한 부분 배열의 합 중 최댓값을 반환한다.

- 부분 배열은 비어 있을 수 없다.
- 원소는 음수일 수 있다.

```kotlin
fun maxSubarray(nums: IntArray): Int
```

## 채점

`performance` 그룹은 **부분 점수**다. 입력 규모가 커질수록 어려워지도록 배치했고,
통과한 케이스 비율만큼 점수를 받는다. O(n²) 풀이도 작은 입력에서는 점수를 얻는다.

| 그룹 | 배점 | 방식 |
|---|---|---|
| sample | 0 | 공개 예제 |
| boundary | 40 | 전부 통과해야 만점 |
| performance | 60 | 통과 비율만큼 부분 점수 |

## 실행 리플레이 계측 (선택)

```kotlin
Drill.visit(index, value)     // 원소를 살펴봤다
Drill.compare(index, other)   // 후보와 비교했다
Drill.match(left, right)      // 최댓값 구간을 확정했다
```

## 제약

- `1 <= nums.size <= 200_000`
- `-10^4 <= nums[i] <= 10^4`

## 예제

| nums | 반환 |
|---|---|
| `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` | `6` |
| `[5, 4, -1, 7, 8]` | `23` |
