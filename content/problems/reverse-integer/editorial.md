# 해설

## 관찰

마지막 자리를 떼어 결과의 뒤에 붙이는 일을 되풀이하면 뒤집힌다. 끝의 0 은 저절로 사라진다 — 앞자리가 되어 값에 기여하지 않는다. 함정은 **넘침**이다. 뒤집은 수가 Int 에 들어가는지를 Int 로 뒤집으면서는 알 수 없다.

## 접근

Long 으로 뒤집는다 — 음수의 나머지가 음수라 부호가 저절로 지켜진다. 끝난 뒤 Int 범위 밖이면 0 이다. Long 없이 하려면 자리를 붙이기 전에 `result > Int.MAX_VALUE / 10` 같은 검사를 한다.

## 복잡도

O(자릿수) 시간, O(1) 공간.

## 발전 과정

문자열로 뒤집기(부호 문자가 끝으로 간다) → 산술로 뒤집기 → 넘침 처리.

## 흔히 무너지는 곳

Int 로 뒤집고 범위를 보지 않는 것. 부호를 잊는 것. 문자열을 그대로 뒤집어 부호 문자가 끝으로 가는 것.
