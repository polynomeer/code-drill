# 해설

## 관찰

만나는 자리에서 바로 행과 열을 채우면 **채운 0 이 다시 기준이 되어** 격자 전체로 번진다. 기준은
원래의 0 뿐이므로, 지울 행과 열을 먼저 모두 정하고 나서 채워야 한다.

## 접근

행 표시와 열 표시를 담을 자리로 **첫 행과 첫 열**을 쓴다. 본문(`r >= 1, c >= 1`)에서 0 을 만나면
`grid[r][0]` 과 `grid[0][c]` 를 0 으로 켠다. 그 다음 본문을 다시 훑으며 표시가 켜진 칸을 0 으로 만든다.

첫 행과 첫 열 자신은 표시판이라 자기 정보를 잃는다. 시작 전에 "첫 행에 0 이 있었나", "첫 열에 0 이
있었나"를 불리언 둘로 기억해 두고 **맨 마지막에** 처리한다.

## 복잡도

O(행 × 열) 시간, O(1) 추가 공간.

## 발전 과정

표시를 담는 불리언 배열 둘(O(행+열))로 푸는 것이 읽기에는 낫다. 상수 공간이 필요할 때만 표시판
기법을 쓴다 — 자료를 자기 안에 겹쳐 두는 대가는 언제나 읽기 어려움이다.

## 흔히 무너지는 곳

- 훑으며 바로 채운다 — 번진다.
- 표시판인 첫 행·첫 열을 본문보다 먼저 지운다 — 표시가 사라진다.
- 첫 열의 원래 0 을 기억하지 않는다.
- 행만 지우고 열을 잊는다.
