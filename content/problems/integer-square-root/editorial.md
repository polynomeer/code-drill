# 해설

## 관찰

"제곱이 n 이하"는 0 에서 시작해 참이다가 어느 지점에서 거짓으로 바뀌고 다시 참이 되지 않는다. 그런 조건의 마지막 참을 찾는 것이 이분 탐색이다. 함정은 곱셈이다 — `mid * mid` 를 Int 로 계산하면 46341 부터 넘쳐 음수가 되고, 음수는 n 이하이므로 조건이 뒤집힌다.

## 접근

`lo = 0`, `hi = min(n, 46340)`. `mid = (lo + hi + 1) / 2` 로 위쪽 가운데를 잡고 `mid² <= n` 이면 `lo = mid`, 아니면 `hi = mid - 1`. 곱은 Long 으로 한다. `lo == hi` 가 되면 그것이 답이다.

## 복잡도

O(log n) 시간, O(1) 공간.

## 발전 과정

0 부터 하나씩 제곱해 보기(O(√n)) → 이분 탐색 → 넘침을 막기. 부동소수점 제곱근을 내림하는 것도 틀린다 — Float 은 큰 정수를 정확히 담지 못하고, 문제도 쓰지 말라고 했다.

## 흔히 무너지는 곳

제곱을 Int 로 계산해 넘치는 것. 조건이 처음 거짓이 되는 값을 답해 하나 큰 것. 가운데를 아래쪽으로 잡아 `lo = mid` 에서 무한 반복하는 것.
