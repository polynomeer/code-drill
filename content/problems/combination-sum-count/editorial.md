# 해설

## 관찰

순서를 세지 않으려면 **후보를 정한 순서로만** 고르면 된다. `i` 번째 후보부터 보되 두 갈래다 — 이
후보를 하나 더 쓴다(`i` 그대로, 남은 합에서 뺀다), 이 후보는 그만 쓴다(`i + 1`). 그러면 같은 조합이
정확히 한 번 나온다.

## 접근

`go(i, remaining)`: `remaining == 0` 이면 1, 후보가 끝났거나 음수면 0, 아니면 `go(i+1, remaining) +
go(i, remaining − candidates[i])`. 상태 `(i, remaining)` 을 기억한다 — 같은 상태가 거듭 나온다.

## 복잡도

상태 `n × target`, 상태마다 O(1) — O(n · target). 표 O(n · target).

## 발전 과정

`ways[t] += ways[t − c]` 를 `t` 바깥, `c` 안쪽으로 돌리면 순열을 센다(`2+3` 과 `3+2` 가 둘). 후보를
바깥 반복으로 두면 조합이다 — 이 문제의 재귀가 바로 그 순서다. 기억 없는 백트래킹은 `target = 500` 에서
지수다.

## 흔히 무너지는 곳

- 순열을 센다.
- 후보를 한 번씩만 쓴다.
- 기억하지 않는다.
