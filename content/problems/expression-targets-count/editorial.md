# 해설

## 관찰

가지가 최대 `4ⁿ⁻¹` 이고 `n ≤ 10` 이라 26 만 갈래 — 다 해 봐도 된다. 어려운 것은 셈이 아니라 **규칙을 빠짐없이 옮기는 것**이다. 곱셈이 먼저이므로 `1 + 2 * 3` 을 왼쪽부터 계산할 수 없다. 대신 지금까지의 값 `total` 과 **마지막으로 더한 항** `last` 를 들고 다니면, 곱셈은 `total - last + last * value` 로 처리된다. 뺄셈 뒤의 항은 음수로 기억해야 `1 - 2 * 3` 이 맞는다.

## 접근

자리 `pos` 에서 끝 `end` 까지를 한 수로 잡고(첫 자리가 0 이면 한 자리에서 멈춘다), 첫 항이면 그대로, 아니면 `+`, `-`, `*` 셋을 각각 재귀한다. 끝에 닿았을 때 값이 목표면 하나 센다.

## 복잡도

O(4ⁿ) 시간, O(n) 공간(재귀 깊이).

## 발전 과정

왼쪽부터 계산하는 백트래킹(곱셈 우선순위를 어긴다) → 마지막 항을 기억하는 백트래킹 → 앞의 0 처리.

## 흔히 무너지는 곳

곱셈을 합 전체에 적용하는 것, 앞에 0 이 오는 수를 허용하는 것, 이어 붙이기를 빠뜨리는 것, 뺄셈 뒤의 항을 양수로 기억해 `1 - 2 * 3` 을 틀리는 것.
