# 해설

## 관찰

`0..n` 전부와 배열의 원소 전부를 함께 보면 빠진 수만 한 번, 나머지는 두 번 나온다. `a xor a = 0` 이므로 전부 XOR 하면 빠진 수만 남는다. 합의 차로도 되지만 `0..n` 의 합은 n = 20만에서 Int 를 넘는다.

## 접근

`acc = n` 에서 시작해 `i` 와 `nums[i]` 를 차례로 XOR 한다. 배열 인덱스가 `0..n-1` 을 채우고 `n` 은 처음에 넣었으므로 `0..n` 전부가 들어간다.

## 복잡도

O(n) 시간, O(1) 공간. 정렬은 O(n log n), 집합은 O(n) 공간.

## 발전 과정

정렬해 첫 빈 자리 → 집합 → 합의 차 → XOR. 넷째가 넘침 걱정이 없는 유일한 것이다.

## 흔히 무너지는 곳

합을 Int 로 계산해 넘치는 것. `0..n-1` 만 XOR 해 n 이 빠진 경우를 놓치는 것. 정렬해 빈 자리를 찾다 끝까지 없으면 0 을 답하는 것.
