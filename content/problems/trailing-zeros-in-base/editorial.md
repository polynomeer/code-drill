# 해설

## 관찰

`n!` 의 `base` 진법 끝자리 0 의 개수는 `base^k` 가 `n!` 을 나누는 가장 큰 `k` 다. `base = p1^e1 · p2^e2 · …` 라면
`base^k` 는 각 `pi` 를 `k·ei` 번 품는다. `n!` 에 든 `p` 의 개수는 르장드르 공식 `⌊n/p⌋ + ⌊n/p²⌋ + …` 이므로, 답은
소인수마다 `⌊르장드르(n, p) / e⌋` 를 구해 **가장 작은 것**이다. 가장 큰 소인수가 늘 답을 정하지는 않는다 —
`base = 12 = 2²·3` 에서 `n = 3` 이면 2 쪽이 묶는다.

## 접근

`d·d <= base` 인 동안 나눠 보며 소인수와 지수를 얻고, 남은 수가 1 보다 크면 그것도 소인수다. 르장드르 공식은
`p^k` 를 곱해 나가지 않고 `n` 을 `p` 로 거듭 나눠 더한다 — `p^k` 는 `n` 이 20 억일 때 `Int` 를 넘는다.

## 복잡도

소인수분해 O(√base), 소인수마다 O(log n). base 가 10 억이면 많아야 3 만 번 남짓이다.

## 발전 과정

10 진법(`base = 10`)은 5 가 묶는 특수한 경우이고, 그것이 "n! 의 끝자리 0" 문제다. 끝에서 0 이 아닌 첫 자리를
구하는 문제는 소인수를 걷어낸 나머지 곱을 따로 들고 가야 한다.

## 흔히 무너지는 곳

- 가장 큰 소인수만 본다.
- 소인수의 지수로 나누지 않는다.
- `p` 의 거듭제곱을 `Int` 로 곱해 넘긴다.
- 나눠 볼 수를 `base` 까지 늘린다.
