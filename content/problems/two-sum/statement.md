# 두 수의 합

정수 배열 `nums` 와 정수 `target` 이 주어진다. 더해서 `target` 이 되는 두 원소의
**인덱스**를 오름차순으로 담은 배열을 반환한다.

- 정답은 항상 정확히 하나 존재한다.
- 같은 원소를 두 번 쓸 수 없다.
- 반환하는 두 인덱스는 오름차순이어야 한다.

```kotlin
fun twoSum(nums: IntArray, target: Int): IntArray
```

## 제약

- `2 <= nums.size <= 100_000`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

## 예제

| nums | target | 반환 |
|---|---|---|
| `[2, 7, 11, 15]` | `9` | `[0, 1]` |
| `[3, 2, 4]` | `6` | `[1, 2]` |
