# 해설

## 관찰

정점과 간선을 다시 지나도 된다. 그래서 어떤 경로를 걸었는지는 중요하지 않고 **어떤 정점들을
방문했는가**와 **지금 어디 있는가**만 중요하다. 그 둘이 상태이고 상태는 `2^n · n` 개다 —
`n ≤ 12` 가 그것을 허락하는 크기다.

## 접근

상태 `(mask, u)` 위에서 BFS 한다. 간선 하나가 비용 1 이라 BFS 가 최단이다. 시작점은 아무 데나이니
모든 `s` 에 대해 `(1 << s, s)` 를 거리 0 으로 큐에 넣고 한꺼번에 시작한다(다중 시작). 이웃 `v` 로
가면 `mask | (1 << v)` 이고, 그것이 가득 찬 순간의 거리가 답이다. 같은 상태는 한 번만 넣는다.
정점이 하나면 0 이다.

## 복잡도

상태 `2^n · n`, 상태마다 이웃 수 — O(2^n · n · deg). 12 에서 상태 49,152 개.

## 발전 과정

방문 순서(순열)를 다 시도하고 쌍마다 최단 거리를 더하는 것은 `n!` 이라 12 에서 4 억이다. 상태를
집합으로 압축하는 것이 지수를 계승에서 2 의 거듭제곱으로 내린다.

## 흔히 무너지는 곳

- 정점을 다시 지나지 못하게 한다 — 별 모양에서 답이 없다.
- 정점 0 에서만 출발한다 — 시작점을 고를 수 없어 답이 커진다.
- 상태를 집합만으로 둔다 — 어디 서 있는지를 잊어 이어질 수 없는 걸음을 잇는다.
