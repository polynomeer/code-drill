# 해설

## 관찰

`x` 이하의 양의 정수 가운데 `a`, `b`, `c` 중 하나 이상의 배수인 것의 개수는 포함·배제로 바로 나온다.

`f(x) = x/a + x/b + x/c − x/lcm(a,b) − x/lcm(b,c) − x/lcm(a,c) + x/lcm(a,b,c)`

`f` 는 `x` 에 대해 줄지 않는다. `n` 번째 수는 `f(x) ≥ n` 인 가장 작은 `x` 다.

## 접근

`[1, 2·10^9]` 에서 `f(mid) ≥ n` 이면 위쪽 끝을, 아니면 아래쪽 끝을 당기는 이분 탐색이다. `f(x) = n` 인 `x` 는 답부터
다음 수 직전까지 여럿이므로 같은 값을 찾았다고 멈추면 안 된다 — 가장 작은 것을 찾을 때까지 좁힌다.

최소공배수는 `lcm(x, y) = x / gcd(x, y) · y` 다. 두 수의 최소공배수는 `10^18` 이하라 `Long` 에 들지만, 거기에 셋째 수를
곱하면 넘칠 수 있다. 답의 상한보다 큰 최소공배수의 몫은 언제나 0 이므로 상한 + 1 로 잘라 둔다.

## 복잡도

이분 탐색 31 번, 한 번에 나눗셈 일곱 번 — O(log(상한)) 시간, O(1) 공간.

## 발전 과정

"답을 추측하고 개수로 확인하는" 틀은 정렬된 행렬의 k 번째 수, 곱셈표의 k 번째 수와 같다. 나누는 수가 많아지면 포함·배제의
항이 `2^k` 로 늘어난다.

## 흔히 무너지는 곳

- 셋의 최소공배수 항을 다시 더하지 않는다.
- 최소공배수를 자르지 않아 넘친다.
- 개수가 정확히 `n` 인 `x` 를 하나 찾으면 바로 돌려준다.
- 하나씩 세어 올라가거나, 세 배수열을 `n` 번 병합한다.
