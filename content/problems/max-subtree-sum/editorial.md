# 해설

## 관찰

서브트리 합은 자식들의 서브트리 합에 자기 값을 더한 것이다. 자식이 부모보다 먼저 정리돼야 하므로, 루트에서 시작한 방문 순서를 거꾸로 훑는다.

## 접근

자식 목록을 만들고 루트에서 반복 DFS 로 방문 순서를 뽑는다. 순서를 거꾸로 훑으며 total[v] 를 부모에 더하고, 최댓값을 갱신한다. 재귀는 깊은 사슬에서 스택이 넘친다.

## 복잡도

O(n) 시간, O(n) 공간.

## 발전 과정

정점마다 서브트리를 다시 훑는 O(n²) → 한 번의 후위 순서.

## 흔히 무너지는 곳

음수 자식을 더하지 않는 것 — 그것은 다른 문제다. 최댓값을 0 에서 시작해 전부 음수인 입력에서 틀리는 것. 인덱스 역순을 자식→부모 순서로 착각하는 것.
