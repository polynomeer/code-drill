# 해설

## 관찰

각 위치에서 오른쪽을 끝까지 훑으면 같은 구간을 반복해서 본다. 아직 답을 못 찾은 위치들을 쌓아 두면 새 값이 올 때 그보다 작은 것들의 답을 한꺼번에 채울 수 있다.

## 접근

인덱스 스택을 둔다. 새 값이 스택 꼭대기 값보다 크면 꺼내며 거리를 채우고, 그 뒤 새 인덱스를 쌓는다. 스택에 남은 것은 0 이다. 스택의 값은 항상 내림차순이다.

## 복잡도

O(n) 시간, O(n) 공간 — 각 인덱스가 한 번 들어가고 한 번 나온다.

## 발전 과정

위치마다 오른쪽 훑기 O(n²) → 단조 스택 O(n).

## 흔히 무너지는 곳

같은 값을 '더 큰 값'으로 세는 것. 스택에 남은 것을 0 으로 채우지 않는 것.
