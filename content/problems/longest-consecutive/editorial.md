# 해설

## 관찰

집합이 있으면 "v+1 이 있는가"가 O(1) 이다. 그런데 모든 값에서 위로 세면 길이 L 인 수열이 L² 비용을 낸다. **`v-1` 이 없는 값만 시작점**이고, 시작점에서만 세면 각 값이 한 번만 세어진다.

## 접근

값을 해시 집합에 넣는다. 배열을 돌며 `v-1` 이 집합에 있으면 건너뛰고, 없으면 `v+1, v+2, …` 가 있는 동안 센다. 최댓값이 답. `v+1` 은 Int.MAX_VALUE 에서 넘치므로 Long 으로 센다.

## 복잡도

O(n) 시간, O(n) 공간. 정렬은 O(n log n). 시작점 검사가 없으면 O(n²) — 20 만 길이 수열 하나가 200 억이다.

## 발전 과정

정렬 후 훑기 → 집합 + 모든 값에서 세기 → 시작점에서만. 셋째가 "같은 일을 두 번 하지 않는다"의 예다.

## 흔히 무너지는 곳

같은 값을 길이에 넣는 것. 시작점 조건을 뒤집는 것. v+1 을 Int 로 계산해 넘치는 것. 시작점 검사 없이 세는 것.
