# 해설

## 관찰

"같은 모양"은 문자 사이의 **일대일 대응**이 있다는 뜻이다. 조건이 둘인 이유가 그것이다 — 같은 문자가 늘 같은 문자로 가는 것(함수)과, 서로 다른 문자가 서로 다른 문자로 가는 것(단사). 한 방향의 표만 두면 둘째 조건이 빠진다: `badc` 와 `baba` 에서 d 와 c 가 모두 a 로 가는 것을 앞 방향 표는 막지 못한다.

## 접근

길이가 다르면 0 이다. 자리를 나란히 훑으며 first→second 표와 second→first 표를 함께 둔다. 어느 쪽이든 이미 적힌 대응과 다르면 0, 끝까지 가면 1 이다. 다른 길도 있다 — 각 자리에서 "그 문자가 처음 나온 자리"가 두 문자열에서 같은지 보면 표가 하나로 줄어든다.

## 복잡도

O(n) 시간, 서로 다른 문자 수만큼의 공간.

## 발전 과정

앞 방향 표 하나 → 반례를 만나 뒤 방향 표를 더하기. 이 문제는 알고리즘보다 **조건을 빠짐없이 읽는 것**이 어렵다.

## 흔히 무너지는 곳

한 방향만 기억하는 것. 길이가 다른 것을 확인하지 않고 짧은 쪽까지만 보는 것. 서로 다른 문자의 개수만 비교하는 것 — 개수가 같아도 자리가 다르면 다른 모양이다.
