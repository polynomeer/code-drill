# 해설

## 관찰

동시에 몇 개든 할 수 있으므로 일 `v` 가 끝나는 시각은 **선행 일들의 끝나는 시각 중 최댓값 + `durations[v]`** 다. 합이 아니다 — 선행 일들은 서로 나란히 진행된다. 답은 모든 끝나는 시각의 최댓값이고, 그것은 그래프의 가장 긴 가중 경로다.

## 접근

칸 알고리즘으로 위상 순서를 돈다. 진입 차수 0 인 일부터 꺼내 끝나는 시각을 확정하고, 뒤따르는 일의 "선행 최댓값"을 갱신하며 진입 차수를 줄인다. 꺼낸 일이 n 개보다 적으면 순환이 있다. 같은 관계가 두 번 나와도 진입 차수와 감소가 같이 두 번이라 문제없다.

## 복잡도

O(n + m). 기억 없는 재귀는 마름모가 겹칠 때 지수적이다.

## 발전 과정

모든 순서 열거 → 재귀 + 기억 → 위상 순서 한 번. 학기 문제와 같은 순서에서 값만 "층 번호"에서 "가중 경로 길이"로 바뀌었다.

## 흔히 무너지는 곳

선행을 더하는 것. 번호 순서를 믿는 것. 순환을 무시하고 부분 답을 돌려주는 것.
