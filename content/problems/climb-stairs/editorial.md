# 해설

## 관찰

n 번째 계단에 오는 마지막 걸음은 1칸이거나 2칸이다. 그래서 n 에 이르는 방법 수는 n-1 과 n-2 에 이르는 방법 수의 합이다.

## 접근

작은 n 부터 채워 올라간다. 직전 두 값만 있으면 되므로 배열 없이 변수 둘로 민다. 더할 때마다 나머지를 취한다.

## 복잡도

O(n) 시간, O(1) 공간.

## 발전 과정

재귀로 두 갈래를 다 따라가면 같은 부분 문제를 지수적으로 다시 푼다 → 메모이제이션 O(n) → 직전 둘만 남기는 반복 O(1) 공간.

## 흔히 무너지는 곳

마지막에 한 번만 나머지를 취해 그 전에 넘치는 것.
