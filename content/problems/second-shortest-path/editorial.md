# 해설

## 관찰

길은 정점과 간선을 다시 지나도 되므로, 둘째 길은 "가장 짧은 길에서 간선 하나를 바꾼 길"만이 아니다. 간선을
갔다가 되돌아오는 것도 길이고 그것이 가장 짧은 둘째일 때도 있다. 그래서 다른 간선을 빼고 다시 구하는 방법은
틀린다. 대신 정점마다 **거리 둘** — 가장 짧은 것 `first` 와 그보다 **엄격히** 긴 것 중 가장 짧은 것 `second` —
을 다익스트라로 함께 구한다.

## 접근

우선순위 큐에서 `(d, v)` 를 꺼내 `d > second[v]` 면 버린다. 이웃 `u` 로 가는 `nd = d + w` 가 `first[u]` 보다
짧으면 `first[u]` 를 바꾸고 옛 값을 `nd` 로 삼아 다음 검사로 넘긴다. `first[u] < nd < second[u]` 면 `second[u]` 를
바꾼다. 두 경우 모두 큐에 넣는다. 정점은 첫째로 한 번, 둘째로 한 번 꺼내진다. 답은 `second[n-1]` 이다.

## 복잡도

O((n + m) log n) 시간, O(n + m) 공간.

## 발전 과정

같은 틀을 `k` 개로 넓히면 `k` 번째로 짧은 길(정점마다 `k` 번 꺼낸다)이 된다. 0 에서와 `n-1` 에서 각각 최단
거리를 구한 뒤 간선마다 `d0[u] + w + dn[v]` 를 보는 방법도 같은 답을 낸다.

## 흔히 무너지는 곳

- 첫째와 길이가 같은 다른 길을 둘째로 센다.
- 정점을 한 번 꺼내면 닫는다.
- 가장 짧은 길의 간선을 하나씩 빼고 다시 구한다 — 되돌아오는 길을 놓친다.
