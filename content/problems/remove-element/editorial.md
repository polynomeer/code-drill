# 해설

## 관찰

남길 원소의 순서는 그대로이므로, 남길 원소를 앞에서부터 차례로 **앞쪽에 모으면** 된다. 모으는 자리는 읽는 자리보다
늘 뒤에 있으므로(지운 만큼 뒤처진다) 같은 배열 안에서 덮어써도 아직 읽지 않은 값을 망가뜨리지 않는다.

## 접근

읽는 자리 `read` 와 쓰는 자리 `write` 를 둔다. `nums[read]` 가 `value` 가 아니면 `nums[write]` 에 옮기고 `write`
를 하나 늘린다. 끝까지 읽은 뒤 앞의 `write` 개가 답이다.

## 복잡도

O(n) 시간, O(1) 추가 공간.

## 발전 과정

순서를 지키지 않아도 되면 지운 자리를 끝 원소로 메워 옮기는 횟수를 줄일 수 있다 — 이 문제에서는 순서가 바뀌어
틀린다. 같은 틀로 정렬된 배열의 중복 지우기, 0 을 뒤로 보내기를 푼다.

## 흔히 무너지는 곳

- 처음 나온 하나만 지운다.
- 지운 자리로 당겨 온 값을 건너뛴다 — 지울 값이 연달아 있으면 하나가 남는다.
- 끝 원소로 메워 순서를 바꾼다.
- 남긴 개수가 아니라 원래 길이만큼 돌려준다.
