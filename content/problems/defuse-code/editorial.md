# 해설

## 관찰

자리 `i` 의 새 값은 원 위의 연속한 `|k|` 칸의 합이다. `k > 0` 이면 `i+1 .. i+k`, `k < 0` 이면 `i-|k| .. i-1` 이고,
원형이므로 번호는 `n` 으로 나눈 나머지다. 바로 옆 자리의 창은 **한 칸만 다르다** — 앞의 하나가 빠지고 뒤의
하나가 들어온다.

## 접근

첫 자리의 창을 한 번 더해 두고, 자리를 하나씩 옮길 때마다 창의 맨 앞을 빼고 맨 뒤 다음을 더한다. 음수 `k` 의
창은 `i + n + k .. i + n - 1` 로 적으면 양수와 같은 모양이 된다. 모든 자리를 동시에 바꾸므로 결과는 새 배열에 쓴다.

## 복잡도

O(n) 시간, O(n) 공간.

## 발전 과정

누적합을 두 배 길이(배열을 두 번 이은 것)로 만들어 두면 창의 합이 뺄셈 한 번이다. 창의 합이 아니라 창의 최댓값이면
단조 덱이 필요하다.

## 흔히 무너지는 곳

- 창이 배열 끝에서 멈춘다.
- `k < 0` 일 때 자기 자신까지 더한다.
- `k < 0` 인데 다음 자리들을 더한다.
- 자리마다 창을 처음부터 다시 더한다.
