# 해설

## 관찰

앞에서부터 제자리에서 0 을 한 번 더 쓰면 바로 뒤의 아직 읽지 않은 원소를 덮어쓴다. 뒤에서부터 쓰면 덮어쓰는 자리는 이미
읽은 자리뿐이다. 그러려면 먼저 **몇 번째 원소까지 결과에 들어가는지**를 알아야 한다 — 0 은 두 칸, 나머지는 한 칸을
차지한다.

## 접근

한 번 훑어 결과에 들어가는 마지막 원소를 찾는다. 그 원소가 0 인데 남은 칸이 하나뿐이면, 그 0 은 맨 끝에 한 번만 쓰고
나머지에서 뺀다 — 이 경계가 함정이다. 그다음 읽는 자리를 그 앞 원소에서, 쓰는 자리를 배열 끝에서 시작해 앞으로 오며
쓰고, 0 이면 한 번 더 쓴다.

## 복잡도

O(n) 시간, O(1) 추가 공간.

## 발전 과정

새 배열에 써도 되면 앞에서부터 쓰고 길이에서 자르면 끝이다. 제자리가 요구되면 "먼저 세고 뒤에서 쓴다"가 정석이다 —
배열 합치기(merge sorted arrays)의 뒤에서 채우기와 같은 생각이다.

## 흔히 무너지는 곳

- 앞에서부터 제자리에서 덮어쓴다.
- 경계의 0 을 두 번 쓴다.
- 늘어난 배열을 그대로 돌려준다.
- 모든 원소를 두 번 쓴다.
