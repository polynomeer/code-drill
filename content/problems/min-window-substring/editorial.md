# 해설

## 관찰

창이 `t` 를 덮는지는 **글자별로 모자란 수**의 합이 0 인가다. 글자가 들어오고 나갈 때 그 글자의 모자란 수만 바뀌므로, 덮었는지를 O(1) 에 유지할 수 있다.

## 접근

`need[c]` 를 `t` 의 개수로 두고 `missing = |t|`. 오른쪽을 늘리며 `need[c] > 0` 이었으면 `missing` 을 줄이고 `need[c]` 를 하나 뺀다. `missing == 0` 인 동안 길이를 재고 왼쪽 글자를 돌려준다 — 돌려준 뒤 `need > 0` 이 되면 `missing` 을 늘린다. 필요 없는 글자는 음수로 내려가 있다가 돌아올 뿐이다.

## 복잡도

O(|s| + |t|). 시작점마다 세면 O(n²).

## 발전 과정

모든 창 검사 → 시작점마다 늘리기 → 두 포인터 + 모자란 수.

## 흔히 무너지는 곳

글자가 있는지만 보는 것. 왼쪽을 한 칸만 줄이는 것. 대소문자를 같게 보는 것.
