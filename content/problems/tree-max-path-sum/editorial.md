# 해설

## 관찰

경로에는 가장 높은 정점(꼭대기)이 하나 있고, 거기서 아래로 많아야 두 갈래로 내려간다. 정점 `v` 의 **이득**을 "`v`
에서 아래로 한 갈래만 내려가는 경로의 최대 합"이라 하면, 이득은 `values[v] + max(0, 자식 이득의 최댓값)` 이다.
그리고 `v` 를 꼭대기로 하는 가장 좋은 경로는 `values[v] + (양수인 자식 이득 중 큰 둘)` 이다.

## 접근

루트에서 너비 우선 순서를 만들고 **거꾸로** 훑으면 자식이 부모보다 먼저 처리된다. 정점마다 자식 이득 중 큰 둘을
골라(음수는 0 으로) 이득과 꼭대기 경로를 계산하고, 꼭대기 경로의 최댓값을 답으로 한다. 답은 `Int.MIN_VALUE` 에서
시작한다 — 값이 모두 음수면 답은 가장 큰 값 하나다.

## 복잡도

O(n) 시간, O(n) 공간.

## 발전 과정

이진 트리면 자식이 둘뿐이라 "큰 둘"이 곧 양쪽이다. 경로의 정점 수에 상한이 있으면 깊이별 이득을 들고 다니는
트리 DP 가 된다.

## 흔히 무너지는 곳

- 음수인 자식 이득도 붙인다.
- 한 갈래로만 내려가는 경로만 본다.
- 가장 큰 합을 0 에서 시작한다.
- 재귀로 내려가다 깊은 사슬에서 스택이 넘친다.
