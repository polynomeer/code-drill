# 해설

## 관찰

단계는 차례로 일어나고 **각 단계는 앞 단계가 바꾼 배열을 본다.** `[2, 2, 2]` 는 첫 단계에서 `[4, 0, 2]` 가 되고, 둘째
단계는 `0` 과 `2` 를 비교하므로 아무 일도 없다. 원래 배열로 비교하면 `[4, 0, 0]` 이 나온다.

## 접근

배열을 한 번 훑으며 같은 이웃을 만나면 앞을 두 배로, 뒤를 0 으로 바꾼다. 그다음 쓰기 포인터 `w` 를 0 에 두고 다시
훑으며 0 이 아닌 값을 `a[w]` 에 놓고 `w` 를 늘린다. 끝나면 `w` 부터 끝까지 0 으로 채운다. 0 이 아닌 값의 순서가 그대로
남는다 — 맞바꾸기로 0 을 뒤로 보내면 순서가 흐트러진다.

## 복잡도

O(n) 시간, 제자리라 O(1) 추가 공간.

## 발전 과정

"쓰기 포인터로 남길 것만 앞으로 모으기"는 값 지우기, 정렬된 배열의 중복 지우기, 0 밀기와 같은 틀이다. 2048 게임의 한 줄
밀기는 같은 규칙을 0 을 먼저 민 뒤에 적용한다 — 순서를 바꾸면 다른 문제다.

## 흔히 무너지는 곳

- 원래 배열로 비교한다.
- 마지막 쌍을 보지 않는다.
- 0 을 먼저 밀고 두 배로 만든다.
- 0 을 맞바꿔 뒤로 보내 순서를 흐트러뜨린다.
