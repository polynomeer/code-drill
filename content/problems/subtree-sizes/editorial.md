# 해설

## 관찰

정점의 서브트리 크기는 1 + 자식들의 서브트리 크기다. 자식이 먼저 끝나야 부모가 정해지므로, 처리 순서는 **깊은 정점부터**다. 부모 배열의 순서는 그 보장을 주지 않는다.

## 접근

깊이를 구하고(한 번 정한 깊이를 기억하며 위로 올라간다), 깊이 내림차순으로 정점을 늘어놓은 뒤 각 정점의 크기를 부모에 더한다. 자식 목록을 만들어 루트에서 재귀로 내려가도 되지만 20 만 사슬에서 재귀 깊이가 문제가 된다.

## 복잡도

정렬로 O(n log n), 자식 목록과 반복 DFS 로 O(n). 공간 O(n).

## 발전 과정

정점마다 서브트리를 세기(O(n²)) → 자식이 먼저라는 순서 → 깊이 순 처리.

## 흔히 무너지는 곳

배열 순서대로 부모에 더하는 것 — 자식이 앞에 오면 아직 완성 안 된 값을 더한다. 자기 자신을 빼고 세는 것. 직접 자식만 세는 것.
