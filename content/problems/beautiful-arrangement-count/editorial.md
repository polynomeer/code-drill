# 해설

## 관찰

조건은 자리마다 독립이다 — 자리 `i` 에 값 `v` 를 두는 것이 되는지는 `i` 와 `v` 만 보면 안다. 그래서
앞의 자리를 채우며 조건을 어긴 가지는 뒤에서 살아날 수 없고, 바로 잘라도 된다.

## 접근

자리 `1` 부터 채운다. 자리 `i` 에 아직 쓰지 않은 값 `v` 중 `v % i == 0 || i % v == 0` 인 것만
시도하고, 마지막 자리를 넘으면 하나로 센다. 되돌아올 때 사용 표시를 지운다. 자리 `i` 에 올 수
있는 값은 `i` 의 약수와 배수뿐이라 가지가 급격히 줄어 `n = 15` 에서도 수십만 번의 호출이다.

## 복잡도

지수이지만 순열 전부보다 자릿수로 적다. 기억(비트 집합 `2^n`)을 얹으면 O(2^n · n) 으로
묶인다. 공간은 재귀 깊이 O(n).

## 발전 과정

순열을 다 만든 뒤 검사하는 것은 15! ≈ 1.3 × 10¹² 이다. 가지치기가 이 문제의 전부이고, 그 위에
비트 집합 기억은 같은 집합의 답이 같다는 관찰이다.

## 흔히 무너지는 곳

- 한쪽 나눗셈만 본다 — `i % perm[i] == 0` 인 배치를 놓친다.
- 사용 표시를 지우지 않는다 — 첫 가지 뒤의 배치가 사라진다.
- 자리를 0 부터 센다 — 조건이 어긋난다.
