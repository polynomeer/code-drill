# 해설

## 관찰

`i` 를 이진수로 적으면 마지막 자리를 뗀 나머지가 `i` 를 2 로 나눈 몫이다. 그러니 `i` 의 1 비트 수는 `i / 2` 의 1 비트 수에 `i` 의 마지막 자리(홀수면 1)를 더한 것이다. `i / 2` 는 `i` 보다 작으므로, 작은 수부터 채워 나가면 필요한 값이 이미 있다.

## 접근

길이 `n + 1` 의 배열을 0 으로 두고 `1` 부터 `n` 까지 `bits[i] = bits[i / 2] + (i % 2)` 로 채운다. 수마다 계산이 하나라 전체가 선형이다.

## 복잡도

O(n) 시간, O(n) 공간 — 공간은 답 자체다.

## 발전 과정

수마다 비트를 하나씩 세는 O(n log n) → 앞의 답을 재사용하는 O(n). 이 문제의 요점은 "점화식이 있다"는 것을 알아채는 것이다.

## 흔히 무너지는 곳

배열 길이를 `n` 으로 잡아 마지막 수를 빠뜨리는 것. 밀어낸 마지막 자리를 더하지 않는 것 — 홀수마다 1 씩 모자란다.
