# 해설

## 관찰

둘째로 큰 값은 **최댓값이 아닌 값 중 최댓값**이다. 최댓값과 같은 값은 둘째가 아니다 — 그것이 이 문제의 전부다.

## 접근

`first`, `second` 를 아주 작은 값으로 두고 한 번 훑는다. `v > first` 면 `second = first, first = v`; `v < first && v > second` 면 `second = v`. 끝나고 `second` 가 그대로면 -1.

## 복잡도

O(n) 시간, O(1) 공간. 정렬은 O(n log n).

## 발전 과정

정렬해 끝에서 둘째 → 같은 값 거르기 → 한 번 훑기.

## 흔히 무너지는 곳

최댓값과 같은 값을 둘째로 세는 것. 둘째의 초기값을 0 으로 두는 것. 정렬한 뒤 같은 값을 거르지 않는 것.
