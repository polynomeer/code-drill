# n 이하 소수의 개수

정수 `n` 이 주어진다. `n` **이하**의 소수 개수를 반환한다.

```kotlin
fun countPrimes(n: Int): Int
```

`n` 자신도 센다. 수마다 나눠 보는 방법은 `n` 이 커지면 무너지고, 배수를 지워 나가면
한 번에 끝난다.

## 실행 리플레이 계측 (선택)

풀이 과정을 시각적으로 되짚고 싶으면 `Drill` SDK 를 호출한다. 채점 실행에서는
no-op 으로 컴파일되므로 시간·메모리 판정에 영향을 주지 않는다.

```kotlin
Drill.visit(value, 1)   // 소수를 찾았다
Drill.write(value, 0)   // 배수를 지웠다
```

## 제약

- `0 <= n <= 10_000_000`
