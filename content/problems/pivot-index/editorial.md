# 해설

## 관찰

자리 `i` 의 오른쪽 합은 `전체 − 왼쪽 − nums[i]` 다. 전체 합을 한 번 구하면 왼쪽 합만 누적하며 자리마다
O(1) 로 본다.

## 접근

`left = 0` 에서 시작해 자리마다 `left == total − left − nums[i]` 면 그 자리, 아니면 `left += nums[i]`.
맨 왼쪽 자리는 `left = 0` 으로 검사되고, 맨 오른쪽은 오른쪽 합이 0 으로 검사된다. 끝까지 없으면 `−1`.

## 복잡도

O(n) 시간, O(1) 공간.

## 발전 과정

자리마다 양쪽을 더하는 O(n²) 는 10 만에서 느리다. 누적합 배열을 두면 같은 O(n) 이지만 공간이 O(n) 이다.

## 흔히 무너지는 곳

- 자기 자신을 왼쪽에 넣는다.
- 맨 왼쪽 자리를 건너뛴다.
- 가장 오른쪽 균형점을 답한다.
- 전체 합이 0 이면 없다고 지름길을 둔다 — 음수가 있으면 틀린다.
