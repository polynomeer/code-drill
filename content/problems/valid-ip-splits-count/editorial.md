# 해설

## 관찰

조각은 정확히 넷이고 각 길이는 1·2·3 이다. 그래서 가지는 많아야 `3^3 = 27` 개 — 마지막 조각은
남은 글자가 정한다. 백트래킹이지만 상수 크기라 무엇을 시험하는지는 규칙의 읽기다.

## 접근

`go(start, parts)`: 네 조각이면 `start == n` 일 때만 하나로 센다. 아니면 길이 1·2·3 의 조각을
잘라 올바르면 내려간다. 올바른 조각은 `0..255` 이고, `0` 이 아닌데 앞이 `0` 이면 안 된다 — `"0"`
은 되고 `"00"`·`"010"` 은 안 된다. 길이가 4 미만이거나 12 초과면 저절로 0 이다.

## 복잡도

가지 27 개, 조각 검사 상수 — O(1).

## 발전 과정

세 점의 자리를 삼중 반복으로 고르는 것도 같은 답이고 같은 비용이다. 백트래킹으로 쓰면 조각 수가
넷이 아닌 변형에도 그대로다.

## 흔히 무너지는 곳

- 앞의 0 을 허용한다 — `010` 이 조각이 된다.
- 네 조각이 되면 남은 글자를 보지 않는다.
- 255 를 거른다 — `< 255` 가 아니라 `<= 255` 다.
- `0` 하나도 거른다 — 0 으로 시작하는 것을 전부 막으면 `0` 이 사라진다.
