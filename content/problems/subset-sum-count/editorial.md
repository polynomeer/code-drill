# 해설

## 관찰

원소마다 넣거나 안 넣거나 둘로 갈라진다. n ≤ 20 이라 2^20 을 다 세어도 된다. 남은 합이 음수라고 가지를 치면 음수 원소가 있는 입력에서 답을 버린다.

## 접근

i 번째까지 봤을 때 남은 합을 들고 재귀한다. 끝에서 남은 합이 0 이면 1 이다. 빈 부분집합도 센다.

## 복잡도

O(2^n) 시간, O(n) 재귀 깊이.

## 발전 과정

이 문제는 완전탐색이 곧 정답이다. 제약을 읽었는가를 재는 문제다.

## 흔히 무너지는 곳

음수가 있는데 가지를 치는 것. 빈 집합을 세지 않는 것. 합이 맞는 순간 멈춰 0 을 더한 집합을 놓치는 것.
