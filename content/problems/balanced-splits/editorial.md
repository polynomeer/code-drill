# 해설

## 관찰

전체 합을 `total`, 왼쪽 덩어리의 합을 `left` 라 하면 오른쪽은 `total − left` 다. 두 합이 같다는 것은 `2 × left == total` 이다.
`left == total / 2` 로 비교하면 `total` 이 홀수일 때 내림 때문에 같지 않은 것을 같다고 본다.

## 접근

전체 합을 한 번 구한다. 자르는 자리 `i = 0 .. n−2` 마다 `left` 에 `nums[i]` 를 더하고 `2 × left == total` 이면 센다. `i = n−1` 은
오른쪽이 비어 빠진다 — `total` 이 0 이면 그 자리도 등식을 만족하니 특히 조심한다. 합은 `2 × 10^14` 까지라 `Long` 이다.

## 복잡도

O(n) 시간, O(1) 공간.

## 발전 과정

"전체 합과 누적합으로 나머지 쪽을 안다"는 피벗 인덱스, 세 덩어리로 자르기(누적합이 total/3, 2·total/3 인 자리의 짝 세기)로
이어진다.

## 흔히 무너지는 곳

- 오른쪽이 빈 자르기까지 센다.
- `total / 2` 와 비교한다.
- 합을 `Int` 로 더한다.
- 같아지는 자리를 하나만 센다.
