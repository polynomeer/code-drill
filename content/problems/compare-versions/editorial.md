# 해설

## 관찰

버전은 문자열이 아니라 **정수의 목록**이다. `10 > 9` 지만 문자열로는 `"10" < "9"` 이고, `1.0` 과 `1.0.0` 은 목록으로 보면 `[1, 0]` 과 `[1, 0, 0]` — 빠진 자리를 0 으로 채우면 같다.

## 접근

점으로 나눠 자리마다 정수로 바꾼다. 긴 쪽 길이만큼 돌며 짧은 쪽의 빠진 자리는 0 으로 본다. 처음 다른 자리가 답을 정하고, 끝까지 같으면 0 이다. 자리가 Int 의 끝까지 가므로 뺄셈 대신 비교 연산자를 쓴다.

## 복잡도

O(|a| + |b|).

## 발전 과정

문자열 비교 → 자리별 문자열 비교 → 자리별 정수 비교 + 0 채우기. 앞의 0 은 정수로 바꾸는 순간 사라진다.

## 흔히 무너지는 곳

자리를 문자열로 비교하는 것. 공통 자리가 같으면 긴 쪽이 크다고 보는 것. 공통 자리만 보고 나머지를 무시하는 것. 큰 자리의 차를 Int 뺄셈으로 구하는 것.
