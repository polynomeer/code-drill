# 해설

## 관찰

거래 기록은 사람마다의 잔액으로 줄일 수 있다. 잔액이 0 이 아닌 사람이 `k` 명이면 `k − 1` 번으로 언제나 끝난다 — 한 줄로
세워 앞사람이 누적액을 다음 사람에게 넘긴다. 이보다 줄이려면 잔액의 합이 0 인 무리들로 나눠 무리마다 따로 정리해야 한다.
`m` 개의 무리로 나누면 `k − m` 번이고, 이보다 적게는 안 된다(송금 그래프의 연결 요소마다 합이 0 이고, 요소 하나는 적어도
크기 − 1 개의 간선이 필요하다). 그래서 답은 `k − (합이 0 인 무리로 가장 많이 쪼갠 수)` 다.

## 접근

`k ≤ 20` 이니 부분집합을 비트마스크로 나타낸다. `groups[mask]` 를 "mask 를 합이 0 인 무리로 가장 많이 쪼갠 수"로 두면,
`groups[mask] = max(groups[mask − i]) + (sum(mask) == 0 ? 1 : 0)`. 사람을 한 명씩 더해 가는 순서로 보면, 합이 0 인
부분집합에 이르는 순간 무리 하나가 닫힌다. 합은 가장 낮은 비트를 뗀 부분집합의 합에 그 사람의 잔액을 더해 구한다.

빈 부분집합은 합이 0 이지만 무리가 아니다 — `groups[0] = 0` 이다.

## 복잡도

O(2^k · k) 시간, O(2^k) 공간 — `k = 20` 이면 2 천만 걸음.

## 발전 과정

"부분집합을 합이 0 인(또는 목표인) 무리로 나누기"는 같은 합의 k 부분 분할, 일을 사람에게 나누는 문제와 같은 비트마스크
DP 다. 짝지어 보는 백트래킹(앞사람의 잔액을 반대 부호의 뒷사람에게 넘겨 보기)도 맞고 사람 수가 작으면 충분하지만, 쪼갤 수
없는 잔액이 많으면 가지가 폭발한다.

## 흔히 무너지는 곳

- 잔액이 있는 사람을 한 줄로 세워 `k − 1` 이라고 한다.
- 금액이 딱 맞는 둘만 짝짓고 나머지는 한 줄로 세운다.
- 가장 많이 빚진 사람과 가장 많이 받을 사람을 맞춘다(탐욕).
- 빈 부분집합을 무리로 센다.
- 짝지어 보는 백트래킹이 스무 명에서 끝나지 않는다.
