# 해설

## 관찰

부분 행렬을 오른쪽 아래 모서리 `(i, j)` 로 센다. 열마다 `(i, j)` 위로 이어진 1 의 개수(높이) `h[j]` 를 들면, 오른쪽 아래가
`(i, j)` 이고 왼쪽 끝이 `k` 인 부분 행렬은 `min(h[k..j])` 개다. 그러니 `(i, j)` 의 개수는 `k = j, j−1, …` 로 가며 지나온 최솟값의
합이다.

## 접근

그 합 `sum[j]` 를 이어 붙인다. 왼쪽에서 처음 만나는 `h[j]` 보다 낮은 열을 `p` 라 하면, `k` 가 `p+1..j` 인 동안 최솟값은 `h[j]` 라
`h[j] × (j − p)` 이고, `k ≤ p` 부터는 최솟값이 `(i, p)` 에서와 같아 `sum[p]` 다. `p` 가 없으면 `h[j] × (j + 1)` 이다. `p` 는 행마다
단조 스택(높이가 늘어나는 열들)으로 찾는다. 0 을 만나면 높이를 0 으로 되돌린다.

수는 10^12 까지 가므로 `Long` 으로 세고 마지막에 나머지를 취한다.

## 복잡도

O(m·n) 시간, O(n) 공간.

## 발전 과정

히스토그램의 가장 큰 직사각형, 모두 1 인 가장 큰 직사각형과 같은 "행마다 높이 + 단조 스택" 틀이다. 거기서는 최댓값을 찾고 여기서는
개수를 더한다는 것만 다르다.

## 흔히 무너지는 곳

- 0 을 만나도 높이를 되돌리지 않는다.
- 왼쪽에 더 낮은 열이 없을 때 열을 하나 덜 센다.
- 개수를 `Int` 로 센다.
- 정사각형만 센다.
- 모서리마다 왼쪽으로 하나씩 늘려 간다.
