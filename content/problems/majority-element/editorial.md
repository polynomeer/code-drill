# 해설

## 관찰

과반수 원소는 다른 값 하나와 짝지어 지워 나가도 살아남는다 — 절반보다 많으니 지울 상대가 먼저 떨어진다. 그러니 후보 하나와 개수 하나만 들고 훑으면 된다. 이것이 서는 이유는 "과반수가 항상 존재한다"는 약속 때문이다. 약속이 없다면 마지막 후보를 한 번 더 세어 확인해야 한다.

## 접근

후보와 개수 0 으로 시작한다. 개수가 0 이면 지금 값을 후보로 삼는다. 값이 후보와 같으면 개수를 올리고 다르면 내린다. 끝났을 때의 후보가 답이다.

## 복잡도

O(n) 시간, O(1) 공간. 해시맵으로 세어도 O(n) 이지만 O(n) 공간이다.

## 발전 과정

세어서 최댓값 → 정렬해서 가운데 → 후보와 개수 (Boyer–Moore 투표). 세 번째가 이 제약에서만 가능한 풀이다.

## 흔히 무너지는 곳

개수가 0 이 돼도 후보를 바꾸지 않는 것. 앞 절반만 보고 결정하는 것 — 과반수가 뒤에 몰려 있을 수 있다.
